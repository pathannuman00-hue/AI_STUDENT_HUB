
# 🎓 AI Campus Hub – AI-Powered Student Activity Recommendation System

## 📌 Project Overview
AI Campus Hub is a web-based application designed to help students discover suitable college activities based on their interests, skills, and preferences.

It also provides AI-powered resume analysis to identify strengths and weaknesses and suggest improvements for students.

## ✨ Key Features

- 🤖 **AI Activity Recommendation:** Suggests suitable activities based on students' interests and hobbies.
- 📄 **AI Resume Analyzer:** Analyzes resumes and provides feedback on strengths and weaknesses.
- 📊 **Dashboard:** Displays student activity information and insights.
- 📝 **Activity Management:** Allows users to manage and explore different activities.
- 💬 **Sentiment Analysis:** Analyzes feedback and identifies user opinions.

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Google Gemini AI (where configured)

## ⚙️ Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/pathannuman00-hue/AI_STUDENT_HUB.git
   ```

2. Navigate to the project directory:

   ```bash
   cd AI_STUDENT_HUB
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure your environment variables and API key in a local `.env` file if required.

5. Run the application:

   ```bash
   python app.py
   ```

6. Open your browser and visit:

   ```text
   http://127.0.0.1:5000/
   ```

## 🎯 Project Objective

The main objective of AI Campus Hub is to make student activity discovery easier through artificial intelligence and help students understand their skills, interests, and areas for improvement.
